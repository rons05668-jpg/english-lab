## 3. 内容校验明细

校验器 `scripts/validate-articles.mjs` 逐条检查并拦下以下问题：

- JSON 结构与字段类型、id 格式与全局唯一、level 与文件一致
- 词数落在等级区间（L1 90–175 / L2 140–275 / L3 230–430 / L4 280–480）
- 每句必须有中文译文
- `grammar[].en` 与 `quiz[].evidence` **必须逐字出现在正文中**（这是最容易被编造的部分，用机器强制）
- 题目 3–5 道、选项恰好 4 个、`answer` 合法、`whyWrong` 恰好 3 条、题型至少覆盖 3 种
- `glossary` 键必须小写原形、条数下限、值必须含中文
- 占位文本（TODO / Lorem / 待补充内容）直接报错

结果：**30 篇全部通过**，0 错误。规模：7,028 词 / 424 句 / 134 题 / 90 个语法点 / 1,289 条词汇释义。

## 5. 修复过的真实缺陷

测试不是走过场，以下是跑出来并修掉的问题：

1. **路由不匹配**：`RouteName` 用 `reader`，但导航链接写 `/read/:id`，导致打开文章显示「页面不存在」。修复：`parseHash` 增加别名映射。
2. **`studies` 未归并到 `study`**：基础词表包含变形词，identity 规则短路了词形还原。修复：`buildBaseKnown()` 剔除不规则变形与规则可还原的变形。
3. **复习页「显示答案」按钮不可见**：样式表里 `.rv-actions--hidden` 是 `visibility: hidden`，而我把它用成了「隐藏评分按钮」的语义。修复：改用 `rv-actions--center`。
4. **「点击句子看译文」实际上点不到**：句子里几乎全是单词，点击基本被单词接走。修复：新增段落级「全段译文」按钮作为主路径，句子级点击保留。
5. **浮层背景透明、正文透字**：`backdrop-filter` 叠加动画层在无 GPU 合成环境下不绘制背景。修复：浮层改为不透明实色，玻璃质感只保留在背景为纯色的区域。
6. **浮层溢出屏幕底部**：释义异步返回后高度变化，初次测量失效。修复：`ResizeObserver` 重新定位 + 视口内收敛。
7. **浮层头部排版错乱**：关闭按钮换行、发音按钮错位。修复：重排 header 结构，音标与发音按钮成对不可拆。
8. **断词把单词拆到两行**（`peo-ple`）：`hyphens: auto` 破坏点击区域与阅读流畅度。修复：关闭断词。

## 6. 未覆盖 / 未验证

诚实说明，以下没有做自动化验证：

- **真实 GPU 渲染下的玻璃效果**：headless 环境无 GPU，`backdrop-filter` 的表现可能与真机不同。已在真机浏览器手动确认侧栏/顶栏正常，但未做像素级对比。
- **Safari / Firefox**：只在 Chromium 上跑了端到端。CSS 里用了 `color-mix()`、`env(safe-area-inset-*)`、`mask-image`，Safari 16+ 与 Firefox 113+ 支持，但未实测。
- **屏幕阅读器**：只做了语义标记与焦点可达性检查，没有用 NVDA / VoiceOver 实际朗读验证。
- **iOS 真机触摸**：用 390×844 视口模拟，未在真机验证手势与 `env(safe-area-inset-bottom)`。
- **长时使用的数据规模**：单测覆盖了去重与级联，但没有跑「数千生词」的压力场景。
- **在线词典路径**：本机 `dictionaryapi.dev` 的 SSL 连接失败（`curl` 返回 000），该分支只有超时/失败的降级路径被间接验证，成功解析路径未在真实网络下验证。
