# 内容扩充交付记录

本次在原仓库上追加 12 篇原创教学文章，总数由 30 增至 42；四个级别分别为 11、11、11、9 篇。原有文章和学习数据标识保持不变。

新增主题包括图书馆、做饭、上学路线、词汇练习、信息核实、街道树荫、维修与产品设计、任务切换、公交可靠性、绩效指标、推荐系统与弹性工作。人物故事和组织案例为教学情境，不冒充新闻或实证研究。

每篇新增文章提供逐句中文译文、25 条词汇标注、至少两处语法解析、三种理解题型及逐项错因说明。答案位置进行了确定性轮换，避免所有正确选项相同。

最初版本按词频截取了 35,284 个词条；2026-10-28 已改为导入完整可检索数据，详见下方“开源词库扩充”。

词库独立按需加载，首次查非核心词时会加载约 3.44 MB 的词典代码块（gzip 约 1.23 MB），构建会提示该块较大。没有声称其每条释义都经过人工校订。完整出版社权威词典仍待授权选择，见 `DICTIONARY-LICENSING.md`。

同时修复真实保存状态、保存失败提示和重试、阅读进度尾次更新与恢复坐标、键盘查词、浮层焦点返回、缩小屏幕后辅助面板遮挡正文，以及其他文章的词义标注被误称为本文语境义的问题。

本机检查：228 项单元测试通过，64 项 Chromium 浏览器检查通过；内容校验、TypeScript 和 ESLint 通过，生产构建通过（存在上述词库分包体积提示）。浏览器检查含桌面、iPad/iPhone 视口、深色模式、查词收藏去重、刷新持久化、失败重试、手机浮层边界。未在真实 macOS/iOS Safari 设备运行。

持久化仍沿用原项目的版本化 localStorage；未将项目切换为 SQLite，也未宣称已完成云同步或出版社词典接入。不要把 `future-schema.prisma` 当成当前生效的数据库迁移。

启动：`npm ci` 后运行 `npm run dev`。生产预览：`npm run build` 后 `npm run preview`。浏览器测试前执行 `npx playwright install chromium`，测试入口为 `npm run test:e2e`，可用 `BASE_URL` 指定已启动的预览地址。


### 开源词库扩充

从 GitHub 项目 ECDICT 导入完整可检索英汉数据（MIT 许可）：399,200 个带中文释义的英文词头与 56,615 个词形索引。按两字母前缀拆分为 740 个懒加载 JSON 块；单块通常低于 0.8 MB，避免首次查词下载整个词库。
